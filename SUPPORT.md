# Getting help

- **Using NoteNirman:** check the [README](README.md) and the [guides in docs/](docs/). The in-app tutorial also covers the basics.
- **Questions and ideas:** use [GitHub Discussions](https://github.com/Rhytam23/note-saver/discussions). Please do not open an issue for a question.
- **A bug:** [open an issue](https://github.com/Rhytam23/note-saver/issues/new/choose) with the steps to reproduce it, your platform (web, Windows or Android) and the app version.
- **A security problem:** follow [SECURITY.md](SECURITY.md). Please do not post it publicly.
- **Commercial use or licensing:** see [LICENSE-ASSETS.md](LICENSE-ASSETS.md) and email rhytambiswas@gmail.com.

This is a small project run by one maintainer, so replies can take a few days.
